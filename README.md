# A Little Place for You ♡

A cozy get-well-soon page: a letter, gentle reminders, "Open when…" pages, a photo scrapbook, a flower garden and more.

## Run it
Just open `index.html` in a browser. No build step needed.

## Put it online (free) with GitHub Pages
1. Push this repo to GitHub.
2. Go to **Settings → Pages**.
3. Under **Source**, choose **Deploy from a branch**, pick `main` and `/ (root)`, then Save.
4. After a minute your site is live at `https://<your-username>.github.io/<repo-name>/`.
